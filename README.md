# Learning Projects

This repository contains smaller Python scripts, experiments, and programming
projects that I created during my software development learning journey.

Projects that are larger, more complete, or demonstrate a particular skill
have their own repositories on my profile.

## Repository purpose

I use this repository for:

- Small Python scripts.
- Practice exercises.
- Experiments with new concepts.
- Early versions of ideas that may later become larger projects.
- Projects that do not currently need their own repository.

## Important safety notice

Some projects in this repository may not include detailed documentation or
usage instructions. Review the code before running anything, and only execute
it if you understand what it does.

Do not enter passwords, API keys, tokens, or other sensitive information into
any project unless the project specifically explains how that information is
handled safely.

## Project status

The projects in this repository represent different stages of my learning.
Some may be unfinished, experimental, or no longer maintained.

For my more complete projects, see the repositories on my GitHub profile.
